# Support

- Questions and ideas: [GitHub Discussions](https://github.com/dvoraj75/herdr-cowbell/discussions).
- Bugs: the [bug report form](https://github.com/dvoraj75/herdr-cowbell/issues/new/choose).
- Docs: the [docs site](https://dvoraj75.github.io/herdr-cowbell/), including the [troubleshooting page](https://dvoraj75.github.io/herdr-cowbell/troubleshooting/).
- Security problems: see [SECURITY.md](SECURITY.md). Do not file them as public issues.

## What to include in a bug report

- herdr version: `herdr --version`
- cowbell version: `herdr plugin list`
- the `ctl.js status` output (how to run it: see [Checking status with ctl.js](https://dvoraj75.github.io/herdr-cowbell/troubleshooting/#checking-status-with-ctljs))
- the plugin log: `herdr plugin log list --plugin dvoraj75.cowbell`
